**Как погонять вызов:** откройте сайт в двух окнах (второе — инкогнито): в одном войдите мастером и нажмите «Свободен», в другом — клиентом и вызовите SOS.

## Если что-то не так

- Обновить до свежей версии: перезапустите Codespace (меню **Codespaces → Stop**, затем снова открыть) — код подтянется сам.
- Журнал сервера: в терминале `tail -f /tmp/traksos.log`.
- Сбросить всё к начальным данным: `docker compose -f .devcontainer/docker-compose.yml down -v`, затем перезапустить Codespace.

Codespace сам засыпает через 30 минут без действий — так не тратятся бесплатные часы.
