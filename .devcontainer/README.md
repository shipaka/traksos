# ТракSOS — тестовый стенд (рабочая ветка)

**Запуск одним нажатием:** [Открыть актуальную версию в GitHub Codespaces](https://codespaces.new/shipaka/traksos/tree/feature/vehicle-insurance-workflows?quickstart=1).

Проверьте, что открыта ветка `feature/vehicle-insurance-workflows`: на `main` пока не перенесены последние изменения.

После запуска сайт обычно открывается автоматически. Если нет: вкладка **PORTS / Порты** → **ТракSOS (8080)** → **Open in Browser**. Чтобы открыть на телефоне, скопируйте ссылку порта; если доступ закрыт, измените видимость порта в Codespaces с учётом того, что тестовый стенд не предназначен для хранения настоящих персональных данных.

## Как увидеть изменения по страховке

1. Войдите как клиент `+79000000002`.
2. «Гараж» → откройте карточку Scania → «Страхование / техосмотр» → отправьте заявку.
3. В отдельном окне инкогнито войдите администратором `+79000000001`.
4. Перейдите в админку → вкладка **«Страхование и ТО»**. Для прямого открытия добавьте к адресу сайта `#/admin?tab=vehicleServices`.
5. Переведите заявку в «На рассмотрении», затем «Передана партнёру», выберите тестового страховщика и нажмите «Передать страховщику».
6. В третьем окне войдите страховщиком `+79000000041`, завершите страхование с датой полиса или укажите причину отказа. Вернитесь к клиенту и проверьте историю Scania.

**Отдельный кабинет страховщика доступен в рабочей ветке.** Войдите под `+79000000041`: в нём уже есть демонстрационная заявка по DAF. Можно завершить оформление полиса с датой окончания или отклонить с причиной. Страховщик видит только назначенные ему заявки; реальные страховщики/выдача полисов внешними компаниями не подключены.

## Что делать, если версия старая или не открывается

- Старая кнопка `https://codespaces.new/shipaka/traksos` создаёт стенд из `main`. Для новых кабинетов используйте ссылку на рабочую ветку вверху.
- Уже созданный Codespace на `main` не обновляется автоматически до другой ветки — создайте новый по правильной ссылке.
- Код на нужной ветке можно подтянуть через перезапуск Codespace.
- Лог сервера: `tail -n 100 /tmp/traksos.log`.
- Сброс тестовой базы: `docker compose -f .devcontainer/docker-compose.yml down -v`, затем повторно запустите Codespace. **Данные и тестовые заявки будут удалены.**

Codespaces может засыпать при бездействии. GitHub Actions проверяет код, но сам по себе не запускает общедоступный стенд.
