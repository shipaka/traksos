# ТракSOS

> **Продолжение проекта в новом чате и обновление Timeweb:** [NEXT_CHAT_TRACKSOS.md](NEXT_CHAT_TRACKSOS.md) · [пошаговая инструкция сервера](deploy/SERVER_UPDATE_NEXT_CHAT.md). Сначала проверьте текущий SHA `main` и CI. Магазин остаётся закрытым до отдельного разрешения владельца.

Маркетплейс выездной помощи грузовикам в Санкт-Петербурге и Ленобласти: SOS-вызов электрика, диагноста, эвакуатора; заявка мастеру приходит как звонок.

## Что внутри

| Папка | Что это |
| --- | --- |
| `server/` | API на Node.js 22 + PostgreSQL 16, WebSocket для чата и вызовов |
| `web/` | веб-приложение: клиент, водитель, мастер, эвакуаторщик, админ (React, сборка esbuild) |
| `e2e/` | сквозной сценарий в браузере: вход → SOS → вызов мастеру → «Беру» → чат → сумма → отзывы |
| `android/` | приложение для RuStore: сайт внутри, пуши, вызов на весь экран |

## Тестовый стенд в один клик

[![Открыть в GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/shipaka/traksos)

Бесплатная временная машина GitHub: база, сервер и тестовые пользователи поднимаются сами, сайт открывается в браузере. Номера для входа — в `.devcontainer/README.md`, коды входа видны на экране.

## Запуск сервера

```bash
npm install
createdb traksos
DATABASE_URL=postgres://postgres@127.0.0.1:5432/traksos ADMIN_PHONES=+79990000001 npm run dev
```

Миграции применяются сами при старте. Веб-приложение: `npm run build` — сервер раздаёт его на том же адресе. Тесты: `TEST_DATABASE_URL=postgres://…/traksos_test npm test`.

Пока SMS-сервис не подключён (`SMS_PROVIDER=log`), коды **регистрации и восстановления** пишутся в серверный лог; `devCode` возвращается в ответе API только вне production. На публичном сервере пользователи не получают SMS до подключения SMS.ru. Перед выпуском смотрите [предрелизный контроль](deploy/RELEASE-GATES.md).

## Переменные окружения

| Переменная | Зачем | Когда нужна |
| --- | --- | --- |
| `DATABASE_URL` | PostgreSQL | всегда |
| `APP_SECRET` | хэши кодов и токенов | production |
| `ADMIN_PHONES` | номера админов через запятую | всегда |
| `PUBLIC_URL`, `CORS_ORIGINS` | адрес сайта | production |
| `SMS_PROVIDER=smsru`, `SMSRU_API_ID` | коды входа по SMS | перед запуском |
| `PUSH_PROVIDER=rustore`, `RUSTORE_PROJECT_ID`, `RUSTORE_SERVICE_TOKEN` | вызов мастеру как звонок | Android-приложение |
| `PAYMENT_PROVIDER=yookassa`, `YOOKASSA_*` | оплата на сайте | после юриста и бухгалтера |

## Главное в логике

- **Вход** — номер телефона и пароль для уже зарегистрированного пользователя; SMS-код нужен при регистрации и восстановлении пароля. Роли: клиент (владелец), водитель, мастер, эвакуаторщик, сервис, модератор, админ. Водитель привязан к машине владельца.
- **Заявка и SOS** — цена считается сразу: выезд по зоне (КАД, до 30 км, Гатчина … Усть-Луга), за КАД км × 1,5 × ставка, ночью ×1,5, совместный выезд дальше 30 км — 70%.
- **Вызов и торги** — сначала заявка 30 секунд звонит приоритетным (вы с отцом; выключается в админке «Распределение»), потом уходит на торги всем подходящим рядом как звонок. Исполнитель откликается по обычной цене или своей — от 85% до 130%. Клиент видит один список с сортировками «Рекомендуем / Дешевле / Быстрее / Ближе»; в «Рекомендуем» цена весит 15%, рейтинг 35%, так что дешевизной в топ не выйти. SOS: через 90 секунд лучший назначается сам. Эвакуатор — так же, с подачей «сборы + дорога».
- **Статусы** — ищем → принял → в пути → на месте → работает → ждёт подтверждения суммы → готово; отмена и «никто не взял».
- **Сумма** — мастер называет работу, клиент подтверждает или спорит. Выезд зафиксирован при принятии.
- **Чат** — один на заявку; номера телефонов скрываются, «напрямую» и т. п. уходят модератору.
- **Отзывы** — взаимные; вес = (рейтинг автора − 3) / 2 в пределах 0,1–1, у новичка 0,3.
- **Оплата по агентской схеме** — `server/src/payments/`. Наличные работают сразу (долг мастера по сбору и вознаграждению ведётся в учёте). Безнал (СБП/карта с заморозкой выезда) и счета компаниям написаны, но выключены: включаются в настройках площадки `PUT /api/admin/settings/payments {"online": true}`. Платёжный сервис подключается через интерфейс `PaymentProvider`; есть тестовый и заготовка ЮKassa.
- **Оферты** — версии, согласия, уведомление исполнителей о новых условиях не позже чем за 15 дней (289-ФЗ).

Все суммы в API — в копейках.

## Android-приложение (RuStore)

`android/` — оболочка на Kotlin: сайт в WebView, пуши RuStore, вызов на весь экран поверх блокировки с кнопками «Беру» / «Отклонить» и звонком 30 секунд. Собирается в GitHub Actions (workflow «Android»), APK — в артефактах сборки.

Что задать в репозитории (Settings → Secrets and variables → Actions):

| Где | Имя | Что |
| --- | --- | --- |
| Variables | `APP_URL` | адрес сайта, например `https://traksos.ru` |
| Variables | `RUSTORE_PROJECT_ID` | ID проекта Push в консоли RuStore |
| Secrets | `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD` | ключ подписи для RuStore (имя ключа `traksos`) |

Без ключа собирается отладочный APK для проверки на своём телефоне.

## Запуск на сервере

Нужен VPS в России (Timeweb Cloud, Selectel, Yandex Cloud), 2 ГБ памяти, Docker. Образ собирается сам при каждом изменении: `ghcr.io/shipaka/traksos`.

```bash
git clone https://github.com/shipaka/traksos && cd traksos/deploy
cp .env.example .env   # заполнить домен, пароли, номера админов
docker compose up -d
```

Caddy сам получит HTTPS-сертификат, база копируется раз в сутки в `deploy/backups`.
