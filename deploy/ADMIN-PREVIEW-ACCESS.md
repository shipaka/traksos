# TrackSOS: временный просмотр админки на рабочем VPS без SMS

Цель: владелец может открыть с ПК настоящую административную панель и из неё безопасный тренажёр десяти кабинетов, пока SMS.ru проверяет подпись. Тренажёр НЕ копирует все реальные кабинеты: действия в нём локальные и не пишутся в рабочую БД.

## Условия
- Запуск только через SSH на своём VPS; публичного API для этого нет.
- В private `deploy/.env` задан ровно один `ADMIN_PHONES`. Телефон не передаётся в GitHub и не выводится скриптом.
- В базе нет пользователей (скрипт откажется менять/перезаписывать существующие записи).
- Нужно обновление приложения с миграцией `090_operator_preview_admin.sql` и обязательным бэкапом ДО запуска.
- Режим `NODE_ENV=production`, реальный PostgreSQL.

## Запуск
В терминале VPS: `cd /root/traksos && bash deploy/provision-preview-admin.sh`

Команда один раз создаёт учётную запись с ролями `admin` и `master`, случайным **10-значным цифровым кодом** и сроком до **ближайшей полуночи по Москве**. Код генерируется криптографически стойко и ограничен лимитом попыток входа. Пароль показывается только в SSH-терминале. Скриншоты с паролем не отправлять.

На `https://traksos.ru` выбрать «Войти по номеру», ввести телефон из `ADMIN_PHONES`, а в поле «Пароль» — выданный временный цифровой код. В админке раздел «Тестирование всех кабинетов» (после обновления из `main` с PR #16).

После полуночи по Москве новый вход и API с уже выданным токеном перестанут работать: сервер проверяет `admin_preview_until` при каждом запросе. Обычные пароли и пользователи с NULL в этом поле не затронуты.

## Ограничения
- Это не регистрация, не доказательство владения SIM и не постоянный доступ; доверие основано на контроле SSH/VPS и заранее разрешённом номере.
- Нет общего кода (1234/0000), вывода секретов через HTTP, SMS-лог и самовыдачи роли.
- Для постоянного аккаунта нужен отдельно согласованный защищённый переход с установкой нового пароля и отзывом preview-сессий. Не отключать сроки вручную в SQL и не использовать SMS-only восстановление служебной роли.
- Не включать магазин, реальные платежи, push или звонки ради демонстрации.
