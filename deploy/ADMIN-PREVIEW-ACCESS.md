# TrakSOS: архив временного доступа администратора

**АРХИВ / ARCHIVED.** Одноразовое окно просмотра, созданное для одного вечера, завершилось **13 ноября 2026 года в 21:00 UTC (14 ноября в 00:00 по Москве)**. Это не ежедневно возобновляемый доступ. Старый локальный тренажёр десяти кабинетов заменён отдельным тест-центром.

`deploy/provision-preview-admin.sh` намеренно завершает работу с ошибкой до обращения к Docker, конфигурации или базе. Не продлевайте срок, не запускайте архивный серверный скрипт напрямую и не изменяйте учётную запись вручную через SQL.

## Действующий порядок

- Для существующего администратора: обычный вход с действующим паролем на странице https://traksos.ru/#/login. Не передавайте пароль, коды или скриншоты с секретами.
- Для учебных операций: в административном кабинете откройте «Тестирование кабинетов» (на ПК «Открыть тест-центр»). Это защищённый тест-центр с 12 ролями. Для полного цикла предусмотрен отдельный изолированный sandbox. См. [FULL_FIDELITY_SANDBOX.md](FULL_FIDELITY_SANDBOX.md). Наличие кода не подтверждает доступность развернутого стенда.
- При утрате административного доступа сначала проверьте состояние сервера штатным `deploy/doctor.sh`, не раскрывая секретов. Отдельный утверждённый порядок защищённого восстановления или создания первого постоянного администратора необходимо подтвердить у владельца; архивный bootstrap и восстановление служебной роли через обычный SMS не являются допустимой заменой.

## Исторические гарантии

Серверная проверка срока `admin_preview_until`, миграция и регрессионные тесты прежних сессий сохраняются. Истёкшие временные токены не должны становиться действительными. Обычные пароли существующих пользователей не затрагиваются. Никаких изменений SMS, платежей, магазина или рабочей БД этот архивный этап не вносит.

Актуальный вход в учебные кабинеты: [TEMPORARY-DEMO-ACCESS.md](TEMPORARY-DEMO-ACCESS.md). Правила выпуска: [RELEASE-GATES.md](RELEASE-GATES.md).
