# TrackSOS — безопасный тренажёр кабинетов для администратора

Это первый этап задачи #12: в настоящей админке доступен раздел «Тестирование всех кабинетов» по адресу `#/admin/test-center`. Доступен только роли `admin`. Для модератора/мастера маршрут остаётся недоступным.

## Что можно делать
- Переключаться между десятью типами: клиент, автопарк, водитель, мастер, эвакуатор, рембаза, мастер+СТО, страховщик, модератор, администратор.
- Смотреть демонстрационные состояния карточек, локально создавать/принимать/отклонять/завершать фиктивные заявки.
- Проверять текстовые ошибки загрузки, прав и обязательных полей.
- Менять тестовые данные профиля, возвращаться в админку в один клик.

## Строгие границы
- Здесь **не используется живой API** и не подменяется личность реального пользователя.
- Никаких настоящих заказов, сообщений, SMS, push, документов, платежей и изменений баланса.
- Все данные вымышлены и хранятся только в памяти страницы; обновление страницы их сбрасывает.
- Это **не** полная проверка реальных пользовательских кабинетов и не точная копия всех экранов. Реальные кабинеты продолжают проверяться автоматическим браузерным E2E на тестовой базе.
- Для полноценного просмотра и нажатия каждого реального рабочего элемента в будущем потребуется выделенный staging-сервер с отдельной БД, тестовыми ролями и блокировкой внешних интеграций. Нельзя делать «вход от лица любого клиента» в рабочем production.

Тест проверяет все десять вариантов, переключение состояний, отображение ошибок и отсутствие реальных POST/PUT/PATCH/DELETE в API; модератор не может открыть раздел.
