# TrakSOS: временный код для просмотра 10 тестовых кабинетов на ПК

Этот режим предназначен для оценки дизайна и проверок интерактивности, пока не готовы реальные аккаунты. **Он не выдаёт роль администратора, доступ к рабочей базе или настоящее API-соединение от лица клиента.** Кабинеты являются тренажёрами с вымышленными данными.

## На сервере Timeweb после обновления main
Откройте SSH-консоль своего VPS (обычный каталог /root/traksos) и выполните:

```bash
cd /root/traksos
bash deploy/create-demo-code.sh
```

Скрипт отказывается работать вне production, требует подтверждения через команду, проверяет наличие одного настроенного ADMIN_PHONES и запускается только внутри app-контейнера. Условия: обновлённое приложение с миграцией 111, работающий PostgreSQL. Он печатает **новый случайный десятизначный код только в приватной SSH-консоли**. Не присылайте код и скриншот терминала в чат.

## На компьютере
1. Откройте https://traksos.ru/#/preview
2. Введите выданный десятизначный код.
3. Откройте нужную роль. Для возврата используйте «Все кабинеты».
4. Нажмите «Завершить просмотр», когда закончите.

Код действует **4 часа с момента выдачи** или до первого успешного применения; для неверных попыток жёсткий лимит 8. После ввода браузер получает отдельный токен учебного стенда (максимум 2 часа), который живёт только в рамках вкладки и не позволяет использовать настоящие API. Следующий запуск скрипта обнуляет предыдущие учебные сеансы.

Реальные рабочие кабинеты и данные проверяются через настоящие тестовые аккаунты на **отдельном staging-сервере** или через обычный защищённый административный вход. Демо-режим не означает, что живые операции уже прошли тестирование.

## Безопасность обновления
Обновление Timeweb выполнить только при успешных CI и проверке магазина:
```bash
cd /root/traksos
git status --short
git branch --show-current
git fetch origin main
git pull --ff-only origin main
bash deploy/verify-shop-closed.sh
bash deploy/update-site.sh
bash deploy/doctor.sh
```
Внимание: никакого docker compose down -v, git reset --hard, удаления .env или ручного изменения пароля администратора.
