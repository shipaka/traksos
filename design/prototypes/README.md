# TrakSOS — клиентский рабочий дизайн-прототип / версия 0.1

**17 ноября 2026.** Первая реализация нового визуального направления с нуля (не на основе старого эталона). Демонстрация — не действующий сайт, не APK и не подключённая серверная функциональность.

## Как открыть

**Проще всего:** `preview-single-file.html` — автономный HTML со встроенными фотографиями, CSS и JavaScript. Открывается на ПК или Android в браузере, не требует интернета или сервера. Также есть раздельные исходники `index.html`, `styles.css`, `app.js` и `assets/` для дальнейшей адаптации в React.

## Что можно нажать

- Переключение контекста «Водитель / Владелец» (только демонстрация интерфейса, не настоящие права).
- Первый экран с одинаково видимыми «Помощь в дороге» и «Эфиром».
- SOS: выбор мастера / эвакуатора / СТО, форма местоположения и проблемы, открытие локальной демозаявки.
- Заявка: транспорт, описание, шкала пяти этапов, вложения-примеры, тестовый чат и тестовое переключение статусов.
- Эфир: список трёх условных комнат, открытие комнаты, локальная демонстрационная переписка.
- Техника, сервисы, меню, страхование и закрытый магазин — честные состояния без вымышленных API.
- Фото-карточки отдельными оптимизированными WebP (8 оригинальных сгенерированных иллюстраций, не фотографии реальных исполнителей).

## Чего нет

- Нет авторизации, подключения к API, реальных SOS-заявок, загрузки фото, геокодирования, модерации, пушей, платежей, GPS или действующих клиентов.
- Нет готового кабинета курьера, мастера, администрации и склада. Разделы этих ролей предусмотрены отдельно в дизайн-архитектуре PR #121 и в черновой разработке PR #111.
- Не является скриншотом продакшена или проверкой APK на телефоне. Проверки выполнены в Chromium в эмулируемых размерах.

## Проверки (headless Chromium)

- Viewports: 320 × 710, 360 × 780, 390 × 844, 768 × 1024, 1440 × 900.
- На всех размерах: JavaScript без ошибок, нет горизонтального переполнения, открывается Эфир и комната, вводится локальное демосообщение, заполняется SOS-форма, открывается карточка заявки, переключается этап.
- Снимки: `preview-390.png`, `preview-1440.png`, `request-390.png`, `request-1440.png`.
