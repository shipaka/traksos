## Очистка

После каждого подтверждения только соответствующий эталон этой роли имеет силу. Устаревшие версии дизайна должны быть удалены **из активных импортов/путей сборки** после проверки зависимостей и регрессий. Не удалять без аудита код логики, рабочие маршруты, миграции, историю Git и материалы других ещё не утверждённых ролей.
