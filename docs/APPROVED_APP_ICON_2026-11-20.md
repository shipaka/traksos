# TrakSOS — утверждённая иконка приложения, 20 ноября 2026

## Решение владельца
**УТВЕРЖДЕНО.** Третий вариант квадратной иконки и последняя уточнённая полноразмерная версия, представленная в разговоре: тёмный штормовой фон, яркий оранжевый закат, мокрая трасса, большая фура, оранжевая светящаяся рамка и написание **TrakSOS** в верхней части. Не генерировать новый вариант, не перерисовывать логотип, не заменять изображение картинкой с предыдущих этапов.

## Предназначение и ограничения
- Одна и та же иконка из мастер-файла используется для **Android launcher**, **RuStore** и **PWA**. Масштабирование — качественным Lanczos, без изменения соотношения сторон, ретуши, подмены фуры, букв или композиции.
- Иконка **не заменяет** фирменный длинный логотип внутри экранов: его утверждённый исходник — вырезка из `618.png` (`/traksos-brand-logo-approved-618.png`).
- Иконка **не меняет** утверждённый главный экран ПК `617.png`, рабочие кабинеты Android, персонажа TrakBot «Техник №3», нативный splash и графику четырёх услуг.
- Android: `mipmap-mdpi/ic_launcher.png` 48×48, `hdpi` 72×72, `xhdpi` 96×96, `xxhdpi` 144×144, `xxxhdpi` 192×192.
- PWA: `web/public/icon-192.png` 192×192, `web/public/icon-512.png` 512×512.
- RuStore: `branding/tracksos-rustore-icon.png` 512×512.
- Для 48 px мелкие детали закономерно становятся менее различимы; не заменять их другим рисунком без нового согласования.

## Статус внедрения
**Исходник и все 8 размеров записаны в GitHub PR №200.** Файлы по таблице выше теперь заменены в `branding/`, `android/app/src/main/res/mipmap-*/` и `web/public/`, а `scripts/verify-approved.mjs` обновлён на контрольные суммы новой иконки.

- Сайт: `web/index.html`, `web/public/manifest.webmanifest` и ссылка на картинку в `web/src/screens/login.tsx` теперь используют `?v=approved-20261120` для принудительного обновления браузерного кэша после выпуска.
- Перед будущим серверным обновлением `deploy/update-site.sh` проверяет полный SHA-256 утверждённого PNG и двух размеров PWA; если checkout старый или файл заменили, выпуск блокируется **до перезапуска приложения**.
- Android-манифест указывает на те же изменённые `@mipmap/ic_launcher`, поэтому следующая APK-сборка из **этого же коммита или его потомка** использует новую иконку. RuStore PNG также лежит в проекте, но магазин самостоятельно не обновляется.

**Ещё не завершено:** PR №200 пока в статусе Draft, обновление не объединено в `main`, новые CI и APK для последней ревизии не подтверждены. На VPS сейчас ничего не менялось. Для появления новой иконки на живом сайте нужно включить данный коммит в релизную ветку и затем выполнить отдельное утверждённое обновление с контрольной проверкой. Нельзя объявлять новый значок опубликованным в RuStore, пока он фактически не загружен туда.
