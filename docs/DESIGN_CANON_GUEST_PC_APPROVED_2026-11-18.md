## 2. Навигационная шапка (слева направо)

Логотип **TrakSOS** (использовать утверждённый исходный логотип, не генерировать новый); выпадающие: **Услуги → Страхование → Запчасти → СТО и сервисы → Эфир → ТехБаза → Для бизнеса → О платформе**; справа **локация СПб и ЛО / выбранный регион**; кнопки **«Войти»**, **оранжевая «Регистрация»**, **«Хочу работать с TrakSOS»**.

Первые две кнопки относятся к клиентскому входу/регистрации (владелец/водитель). «Хочу работать» — четыре направления партнёров: **выездной мастер (со специализациями), эвакуаторщик, СТО, страховой агент**. Не смешивать эти две регистрации.

Верхние меню обязательно раскрывают реальное содержимое с работающими подпунктами:
- Услуги: помощь SOS, мастер, эвакуация, СТО, консультация, отдельный стационарный ЭБУ.
- Страхование: ОСАГО, КАСКО, страхование грузов, ответственность перевозчика, техосмотр; закрытые направления честно помечать.
- Запчасти: VIN, артикул/название, каталог; без цен/наличия до реальной интеграции.
- СТО: диагностика, ремонт, ТО, запись — только достоверные слоты.
- Эфир: знакомство с сообществом, каналы; личные сообщения только после входа, не симулировать живые данные.
- ТехБаза: категории/анонс видны гостю, **материалы доступны только авторизованным с серверным контролем прав**.
- Для бизнеса: автопаркам/владельцам, сотрудничество/партнёрам.
- О платформе: как работает, регионы, оферты, контакты, поддержка.
Плавное появление 150–300 мс, работа с клавиатурой, ESC, видимый фокус, закрытие кликом вне.

Три кнопки по одной линии, в порядке: **«Вызвать помощь SOS»** (оранжевая), **«Открыть Эфир»**, **«Стать партнёром»** (две контурные). У гостя SOS ведёт через вход/регистрацию к разрешённому заказу; Эфир — обзор/вход; партнёрство — выбор одного из четырёх направлений.

## 4. Центральная часть — 9 карточек, фотографии ОБЯЗАТЕЛЬНЫ

**Слева:** маленькая оранжевая линия, «УСЛУГИ TRAKSOS», крупное «Основные сервисы платформы», пояснение «Практические решения для грузового транспорта — от срочной помощи до профессионального сервиса», нижняя отдельная картинка грузовика на трассе.

**Центр:** большая светло-серая панель, внутри фотокарточки с округлением и маленькими контрастными чёрно-оранжевыми иконками. СТРОГО 4 сверху + 5 снизу, порядок не менять.

**Ряд 1 (четыре):**
1. **Выездной мастер** — реальный мастер у ступицы/колеса грузовика; «Диагностика и ремонт на месте поломки».
2. **Эвакуация** — тяжелый грузовой эвакуатор перевозящий грузовую технику; «Безопасная перевозка грузовой техники до СТО».
3. **СТО** — настоящий грузовой ремонтный бокс, грузовик с поднятым капотом; «Плановое ТО, ремонт и комплексный сервис».
4. **Консультация** — профессиональный оператор в гарнитуре и экраны; «Разбор проблемы, рекомендации и подбор решения».

**Ряд 2 (пять, первая ШИРЕ остальных):**
1. **Специалист ЭБУ** — широкая ТЁМНАЯ карточка, электронный блок на столе в мастерской и диагностика; «Стационарная диагностика и ремонт электронных блоков». Это НЕ выездная услуга.
2. **Страхование** — фото грузовика на трассе; «ОСАГО, КАСКО, грузы и ответственность».
3. **Запчасти** — грузовые тормозные диски/подшипники/фильтры; «Подбор и поставка оригинальных и аналоговых запчастей».
4. **Эфир** — радиоволны/дорожная инфраструктура; «Связь, помощь, опыт и события в сообществе водителей».
5. **ТехБаза** — ноутбук с техническими схемами грузовика; «Техническая документация, схемы, инструкции и база решений». Гостю доступны только описание и вход, не сами материалы.

Изображения должны совпадать **по сюжету и заполнению** с оригиналом; не заменять случайными фото и не оставлять без иллюстрации.

## 5. Карта присутствия справа

Заголовок «Карта присутствия TrakSOS», описание «Покрытие партнёров и доступность сервисов по регионам России», карта, легенда, две кнопки «Подробнее о покрытии» и «Регионы».

**ВАЖНО:** оранжевые точки на утверждённом PNG — **лишь художественный образ**, не реальные партнёры. В рабочем продукте никакие выдуманные точки, рейтинги, области обслуживания и гарантированные выезды не допускаются. Отмечать только реально подтверждённых партнёров, с согласием на публичную точку и корректной геолокацией. Серый цвет означает **отсутствие услуги**, а не правовой статус территории. Регистрацию без покрытия не запрещать автоматически. Крым/Севастополь — возможность будущего подключения при реальных партнёрах; ДНР, ЛНР, Запорожская, Херсонская области без сервиса — серые по статусу покрытия. Границы для российского рынка согласовать с актуальными российскими официальными геоданными и юристом; международно оспариваемые территории требуют отдельной проверки. Стоимость API Яндекс Карт и бесплатные альтернативы — GitHub issue #157. Без данных/ключа — честная статичная или пустая карта без ложных точек, видео вместо карты только после отдельного выбора владельца.

## 6. Нижняя полоса «Почему TrakSOS»

Пять элементов с оранжевыми иконками: **Быстрая помощь в дороге; Проверенные специалисты и СТО; Сообщество профессионалов; Техническая база и практический опыт; Решения для водителей, владельцев и автопарков.** Проверенные/работающие функции маркируются только в соответствии с реальной реализацией.

## 7. Правила внутри открывающихся страниц

- Вход — оформленный полноценно в том же премиальном стиле; номер телефона + пароль; **показать/скрыть пароль** без потери текста; «Забыли пароль»; переход к регистрации; кнопка назад.
- По умолчанию обычный вход по паролю. SMS только при регистрации/восстановлении. Не тратить SMS при каждом входе.
- Все CTA, карточки, выпадающие разделы должны **работать** и иметь осмысленное содержание; не «мертвые» экраны. Если услуга пока не подключена — честное недоступное состояние, а не фиктивная заявка.
- Закрытые данные/ТехБаза/частные Эфир-сообщения/история/пароль защищаются серверным доступом, не только modal блокировкой.
- Плавные переходы, hover, focus/ESC, 320/360/390/768/1440/1672 px, без горизонтального скролла, реальные функциональные тесты. Грузовик справа не обрезается при адаптации.
