# TrakSOS / гостевая главная ПК — v2, сверка с выбранной композицией
Дата: 18.11.2026. **На согласовании; не production.**

## Ориентир дизайна
- Визуальная композиция — выбранный пользователем гостевой вариант №5: широкая фото-сцена вверху, крупный текст слева; сервисы собраны **одной светлой центральной панелью**, слева компактное пояснение, справа карта.
- Карта — пожелания к варианту №7: показывать подтверждённое сервисное покрытие и реальные подтверждённые публичные точки, а не политическое значение цвета. Пока нет лицензированных геометрий/API, вместо рисования неправильных границ показывать честное пустое состояние.
- Фотография Volvo справа: использован существующий отдельно согласуемый кадр, в котором грузовик физически находится в правой части, а текст не перекрывает кабину.
- Экран — **без авторизации**: не показывать «мои заявки», «моя техника», баланс или историю из аккаунта.
- Изображения разделов соответствуют услуге; стационарный ЭБУ не представлен выездным мастером.

## Что не совпадало в v1, и исправление
| Участок | Было | Исправлено в v2 |
|---|---|---|
| Основная композиция | Тёмные фото-карточки отдельными рядами, карта ниже | Светлая панель услуг рядом с отдельной картой, как в референсе |
| Фото-блок | Кабина попадала за текст | Отдельное реалистичное фото грузовика справа, текст слева |
| Эфир | Только главная CTA и неочевидная карточка | Пункт навигации + CTA в hero + отдельная поясняющая карточка без выдуманной ленты |
| Шапка | Неполная навигация | Выпадающие «Услуги», «Страхование», «Запчасти», «СТО и сервисы», «Эфир», «ТехБаза», «Для бизнеса», «О платформе» |
| Вход | Только демонстрационное сообщение | Форма телефон + пароль, «Показать/Скрыть», «Забыли пароль», отдельная регистрация клиента |
| Клиент/партнёр | Нечёткий маршрут | «Войти» и «Регистрация» для клиента, «Хочу работать» для 4 типов партнёров |
| ТехБаза | Открывалась общая заглушка | Видны только названия разделов; материалы защищены и доступны лишь после входа/ACL |
| Страхование | Нет направлений | Выпадающие ОСАГО, КАСКО, грузы, ответственность перевозчика; переход к клиентскому входу |
| Запчасти | Нет состава раздела | VIN/артикул/каталог, при этом честно заявлено, что магазин ещё не опубликован |
| SOS | Нельзя выбрать направление | Отдельные мастер/эвакуатор/СТО, консультация отдельно |
| Переходы | Ссылки только скроллили | Плавные dropdown и модальные переходы; escape, закрытие вне модалки, фокус |
| География | Не хватало фактов | Смена региона без GPS и без ложного покрытия |
| Неясный статус публикации | Можно ошибочно принять макет за продукт | Явная отметка «рабочий дизайн-прототип», данные и SMS не отправляются |

## Что реально протестировано в Chromium
Разрешения 1600×950, 1440×900, 390×844, 320×700: JS pageerrors = 0, горизонтальный overflow = 0.
- 8 меню: непустое содержание и раскрытие.
- 16 разделов модальных окон открываются, закрываются.
- Вход: тип пароля переключается password → text → password, восстановление доступно.
- ТехБаза: гостю видны категории, материалы закрыты.
- Эфир присутствует и открыт только в формате описания, без фиктивных сообщений.
- Регион Крым, ДНР: актуальные честные тексты доступности.
- Форма для клиентской регистрации и отдельная партнёрская регистрация.
- Иллюстрации встроены в HTML (нет зависимости от внешних фотохостингов).
