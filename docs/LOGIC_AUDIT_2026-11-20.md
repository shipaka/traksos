# TrakSOS — ревизия действующей логики, 20.11.2026

Статус: **незавершённая проверка единой ветки, не релиз**. Ревизия исходных файлов и CI, без записи на VPS. Этот документ — список подтверждённых расхождений и проверок, а не утверждение, что сотни веток полностью объединены.

## Подтверждённое и исправленное в PR #199

1. Старые визуальные ассеты, ссылки CSS, Android WebView и сценарии упаковки устаревших ресурсов — удалены/отключены. Внесены автоматические проверки, включая рекурсивный обход web/src. Сохранены настоящие данные клиентов и старые финансовые проводки.
2. Активный YooKassaProvider и четыре переменные YOOKASSA_* убраны из серверного запуска/образца окружения. Адаптер удалён, формирование исторических расчётных документов вынесено в отдельный модуль. Не разрешать PAYMENT_PROVIDER=yookassa.
3. Наличные запрещены для новых заявок в production и sandbox, даже при старых сохранённых настройках; дефолт cash=false. Новые формы не предлагают этот способ, восстанавливаемый черновик не должен включить его повторно. Исторические cash-ledger/возвраты и временные тестовые фикстуры не выданы за действующую оплату. Если нет подключённого способа безнала, оформление платного заказа должно честно блокироваться.
4. Обучение, справку и действующие проекты оферт надо проверять вместе с экономикой, а не опираться на старые README/NEXT.
5. Физические старые инструкции передачи 5, 12, 13 и 16 ноября заменены точечными переходами сюда, вместо советов возвращаться к устаревшим SHA и ЮKassa.

## Открытые дефекты / релизные блокеры

P0-А. **Несоответствие тарифа:** docs/APPROVED_FEE_POLICY_2026-11-19.md описывает лимит 5 000 ₽ только для счетов СТО, а server/src/domain/money.ts использует PER_SIDE_FEE_CAP=500000 как общую границу также для выездных заказов. Пройти согласование и тесты по каждому типу услуги, затем обновить одновременно UI/API/проводки/оферты. Не менять ретроактивно подтверждённые заказы.

P0-Б. **Автоматический бесплатный тариф по признаку приоритета:** defaultSettings.fees.priorityCommissionPct=0, а commissionPct() может обнулять комиссию без отдельной акции. Установить границы приоритета в выдаче и тарифных акций; сохранить исторические снимки комиссии. Не подменять утверждённые 5% скрытой льготой.

P0-В. **Нет рабочего банковского проведения:** Точка умеет только документы-счета с выключенной функцией; банковские оплаты/удержания/возвраты и выплаты нельзя считать подключёнными. До их запуска безналичные платные заявки не должны имитировать оплату.

P0-Г. **Визуал и достоверность ассетов:** одна из старых цепочек проверок требовала уже удалённые партнёрские картинки; публичная демонстрационная карта потеряла прежний графический файл. Требуется новый фактический одобренный визуальный источник, реальные Chromium-кадры 320/360/390/1440/1602 и Android. Не считать фон-градиент фотографией или пустой блок картой.

P0-Д. **Разные исходные ветки:** в docs/ALL_BRANCHES_INVENTORY_2026-11-19.md инвентаризованы 146 веток, многие содержат пересекающийся код. Нельзя автоматически считать все внедрёнными, копировать старые CSS или удалять независимую бизнес-логику без проверки диффов/ACL/миграций.

P0-Е. **Учебные материалы и оферты:** заменить утверждения о наличных/ЮKassa как действующих способах. Нужны согласованные и юридически проверенные оферты каждой роли; документы в GitHub не означают их публикацию.

## Оставляем только как учёт и безопасность

Старые SQL-миграции, проведённые платежи, журнал операций, пользовательские данные, юридически значимые версии оферт и серверные ACL нельзя «удалить к чёрту» без миграции и проверки последствий. Они не должны быть источниками UI и новых тарифов. Git-историю не переписывать: старые PR/ветки не являются текущим эталоном.

## Дополнение: закрытый магазин

Даже если старая PostgreSQL настройка shop.enabled=true, рабочий production/sandbox принудительно возвращает shop.enabled=false. Админ не может незаметно включить продажи старой кнопкой: прежний интерфейс «Открыть магазин» заменён на «закрыт до приёмки», каталог для подготовки сохраняется. Исключение разрешено лишь в изолированной non-production тестовой фикстуре. История старых заказов остаётся читаемой.
