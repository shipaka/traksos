# Необязательные характеристики машины: черновик

Ранее созданная миграция 032 уже содержит VIN, engine, configuration_notes. В этом PR эти поля стали доступны владельцу через раскрываемую карточку гаража. Индикатор 0–3 предложит заполнить, но не блокирует SOS, регистрацию или заявку. Водитель видит данные закреплённого ТС с пояснением «Ограниченный доступ», редактирование запрещено на сервере. Неиспользуемые значения можно очистить. Данные нужны для лучшего подбора запчастей, не считаются доказательством текущей комплектации; неверный VIN не должен автоматически менять артикулы.

Прежде чем внедрять: CI, Android UI/mobile, migration-free upgrade on existing data, role checks for owners vs driver, VIN retention and customer-facing policy. DRAFT — не обновлять продакшен без приёмки.
