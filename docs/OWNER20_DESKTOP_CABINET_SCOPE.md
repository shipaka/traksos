## Что ПОКА ПРЕДЛОЖЕНО ДЛЯ ПК, а не утверждено владельцем
Ни одного окончательно утверждённого общего screenshot-макета всех **десктопных** внутренних кабинетов не обнаружено. Переход на общий стиль 20 ноября — рабочая ветка, до визуальной приёмки.

### Общая сетка
- Верх: тот же логотип и графитово-оранжевая гамма, уведомления, поиск, понятное меню профиля.
- Левая полоса: компактные навигационные разделы **по роли**, активный раздел с оранжевой полосой. Учебник/оферта/помощь — внизу, а не вместо главной работы.
- Центр: главный текущий объект (заявка, машина, запись, предложение или очередь) занимает максимум внимания; 2–3 функциональные зоны, читаемый крупный текст.
- Контекстная зона справа: текущие действия, карта/маршрут, фото марки/модели ТС, сроки, исполнитель, статус, суммы — только если данные действительно существуют; при отсутствии данных честная пустая карточка.
- Метрики и финансовые поля — реальные из API, **никаких иллюстративных** доходов или ETA в рабочем интерфейсе.

### Роли
| Кабинет | Главная рабочая зона | Боковой / дополнительный контекст |
| --- | --- | --- |
| Владелец / клиент | Сервисы SOS, мастер, эвакуатор, СТО, консультация; активные заявки с хронологией | Автопарк, выбранный грузовик, история, карты и оплаты |

| Эвакуаторщик | Заявки на транспортировку и последовательные статусы | Техника, точки погрузки/выгрузки, маршрут, документы |
| СТО / рембаза | Текущие записи, ожидаемые машины, машины в ремонте | Карточка автомобиля, услуги/ремзона, исполнители и финансы |
| Страховой партнёр | Полученные запросы, варианты компаний, статусы подбора | Документы, переписка по карточкам, расчёты и платежи |
| Оператор техосмотра | Назначенные осмотры и результаты, история | Документы и фактические этапы (без фиктивных карт) |
| Модератор | Очередь проверки пользователей, карточек и спорных обращений | Причины решений, обращения и история |
| Администратор | Поисковая операционная панель: заказы, клиенты, партнёры, финансы | Разделы-вкладки, экспорт, диагностика, тест-кабинеты, настройки |

1. Отдельно сверить настоящие скриншоты Chromium каждого кабинета на 1440×900 и Android/WebView 390×844 с ранее принятыми макетами.
2. На любом экране проверить кликабельность, доступность прав, отсутствие горизонтального скролла, контраст, корректность выбранной фото-модели авто.
3. Не переписывать утверждённую логику, деньги или правила доступа ради косметики.
4. Только после проверки и подтверждения владельца: merge, установка на сервер и последующая проверка домена.
