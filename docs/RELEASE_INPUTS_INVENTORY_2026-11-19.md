## Неприкосновенный визуальный канон и юридические границы
- ПК — последний утверждённый пользователем оригинальный макет 18.11, Android — согласованные мобильные экраны 19.11, мобильный браузер — отдельная адаптация 19.11. Ни один старый дизайн не должен перезаписывать эти варианты.
- Работающие роли и серверные статусы важнее декоративных демо-элементов.
- Финансы: 5% клиенту сверху, 5% исполнителю внутри цены с отдельными лимитами 5000 ₽; показывать клиенту только его сбор. Любые изменения на продакшен — после правовой приёмки.
- Точка и любые реальные банковские операции выключены в sandbox. Магазин закрыт. Новые оферты — черновики, не публикации. ИИ/голос/платный TrakBot не включать без явного согласия и источников.
- Изменения учебных текстов и интерактивных курсов должны синхронизироваться с каждой изменившейся логикой или API **в том же выпуске**.
- Успех выпуска: одни и те же SHA для сайта и debug APK; отдельная sandbox PostgreSQL, реальные входы через админку и работа мастера с заявками, чатами и возвратом; исходный VPS production не трогать.
