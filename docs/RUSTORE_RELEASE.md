# TrakSOS → RuStore: подготовка первой версии
Состояние: 12 ноября 2026. Оператор сервиса — владелец проекта. Это технический список для выпуска, не юридическое заключение.

## Идентификаторы и подпись
- Имя: **TrakSOS — помощь грузовикам** (в магазине название должно быть уникальным).
- Android package: `ru.traksos.app`, изменить после первой публикации нельзя.
- Поддержка: Android 7+ в APK (`minSdk=24`); для RuStore важно пройти проверку совместимости с актуальными версиями Android.
- Версии задаются GitHub Actions (`VERSION_CODE` увеличивается на каждом запуске Android-workflow).
- В GitHub Actions уже успешно выполняется **release** сборка. Она подписывается `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, а также alias `traksos` / `ANDROID_KEY_ALIAS` и пароль ключа. Эти секреты не выводить в чат и логи.
- Контрольный сертификат проверенного релизного APK (12.11.2026):
  - SHA-256: `75:FB:F8:37:EB:1E:3A:B9:7E:4B:18:19:A5:64:AC:13:6F:5C:0F:2A:C7:B4:C4:99:EB:1C:16:BE:AD:33:3E:F0`
  - CN=TrakSOS, O=TrakSOS, действителен до 2054 года.
  - Все новые релизы должны иметь **тот же сертификат**, иначе обновление у пользователей не установится.
- **Ключ подписи должен иметь резервную копию у владельца вне GitHub**; без неё перенести приложение на новый процесс сборки невозможно.

## Утверждённая визуальная система
- Заставка Android: фото фирменной фуры TrakSOS из **первого согласованного трёхэкранного коллажа**; индикатор загрузки без маркетинговых карточек; локальный ресурс в `android/app/src/main/res/drawable-nodpi/splash_truck.webp`.
- Иконка приложения: фирменный грузовик cyan/pink на navy, XML `android/app/src/main/res/drawable/ic_launcher_track.xml`; исходный SVG магазина — `branding/tracksos-rustore-icon.svg`. Для карточки нужен PNG **512×512, фон без прозрачных внешних полей**, сделанный из того же SVG.
- Ни в приложении, ни в карточке не упоминать Google Play / App Store: **только RuStore**.

## Предлагаемые тексты карточки (проверить по фактически доступным функциям после запуска)

### Краткое описание (до 80 символов)
Помощь грузовикам в Санкт-Петербурге и Ленобласти: мастера, СТО, эвакуация.

### Полное описание
**TrakSOS** — сервис поиска технической помощи для грузового транспорта в Санкт-Петербурге и Ленинградской области.

Через приложение водитель или владелец грузовика может описать поломку, оформить запрос на помощь и следить за статусом заявки. Доступные направления: автоэлектрика, компьютерная диагностика, пневматика и тормоза, автономные отопители, шиномонтаж, эвакуация, консультации специалистов и партнёрские станции техобслуживания.

Для мастеров и сервисных станций предусмотрены отдельные кабинеты и получение заявок. В мобильном приложении используются уведомления о статусах заявок и входящих обращениях.

Доступность исполнителей и сроки ответа зависят от фактического наличия подключённых специалистов. Регион пилотного запуска: Санкт-Петербург и Ленинградская область.

**Важно:** не заявлять «круглосуточно», «проверенные сотни мастеров», «гарантированный выезд» и реальную онлайн-оплату, пока это не подтверждено в рабочем сервисе.

## Данные / разрешения для декларации RuStore
- `INTERNET`, `ACCESS_NETWORK_STATE`: связь с сервисом и проверка соединения.
- `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`: определение местоположения по инициативе пользователя для заявки на дорожную помощь; должна быть альтернатива ручному адресу.
- `POST_NOTIFICATIONS`: уведомления о заявках, переписке и вызовах.
- `VIBRATE`, `WAKE_LOCK`: сигнал о входящей заявке исполнителю; проверять фактическое поведение.
- `USE_FULL_SCREEN_INTENT`: отдельное чувствительное разрешение для экрана входящей заявки. На Android 14+ по умолчанию может быть недоступно, а RuStore может запросить обоснование; нужно иметь fallback на обычное уведомление.
- Собираемые данные (при использовании соответствующих функций): номер телефона, ФИО/название организации, сведения об автомобиле, место заявки, история заказов и чата, фото/документы исполнителя, push-токен, платёжные сведения в объёме, необходимом для операции. Сопоставить с фактической политикой конфиденциальности и договором.

## Отправка на модерацию — блокеры
1. **Работающий VPS и HTTPS `https://traksos.ru`**. Без сервера релизная оболочка честно показывает экран «Нет связи», и RuStore может отклонить приложение.
2. **SMS-авторизация работает на настоящем телефоне**: `SMS_PROVIDER=smsru`, валидный `SMSRU_API_ID`, пройдены успешный и неуспешный сценарии. `SMS_PROVIDER=log` не подходит для внешних пользователей.
3. Официальная **политика конфиденциальности на русском языке** публично доступна по адресу `https://traksos.ru/#/offer/privacy` и открывается *из приложения*. Редакция, контакты оператора и юрданные заполнены и проверены.
4. Бэкэнд и хранилища ПДн в РФ; проверить договор провайдера и статус уведомления в Роскомнадзор.
5. На Android протестировать: запуск (с/без сети), вход/регистрацию через SMS, SOS, предложение и изменение статуса заявки, чат, загрузку фото/документов, пуши RuStore, отказ в разрешении на GPS/уведомления, удаление аккаунта.
6. В карточке RuStore нужны **не менее трёх реальных скриншотов с установленного Android-приложения**, отражающих его работу (не изображения концептов, не телефонные рамки, не заставка вместо функций). Качество и размеры по требованиям RuStore. Не публиковать скриншоты с реальными ПДн пользователей.
7. Заполнить контакт разработчика, корректную возрастную категорию, раздел конфиденциальности, чувствительные разрешения. Если возможности закрыты авторизацией, обеспечить модератору рабочий тестовый вход/описание процесса, не добавляя тайных бэкдоров.
8. ЮKassa, если не настроена, **не заявлять как рабочую** и не включать реальные списания; тестовые и боевые креденшиалы не смешивать.
9. **После успешной проверки подписанного APK** загрузить его в RuStore Console: Приложения → Добавить → Загрузить версию. Рекомендуется альфа-тестирование 2–3 устройствами до публичной модерации.
10. Дождаться прохождения модерации и реального URL карточки; только тогда заменить на сайте надпись «Скоро в RuStore» на ссылку.

## Как забрать APK
GitHub → `shipaka/traksos` → Actions → `Android` → успешный запуск с актуальным коммитом → Artifacts → `traksos-release-N`.
Это ZIP, внутри `app-release.apk`. Debug и release не смешивать; **в RuStore загружать только релиз**.
Нельзя изменять пакет или подпись после отправки первой версии.
