# TrackSOS · Каталог транспорта, профессиональные источники и проверенная доступность (2026-11-17)

## Объём реализованного пакета

Продолжение PR #143 (#91/#92), на той же отдельной feature-ветке.
Без обновления VPS, открытия магазина, изменения платёжной модели или слияния других PR.

### Реальная загруженная база

- \`server/data/vehiclesdb_2026_11_11.json\`: лицензированный срез **VehiclesDB 2026.11.11**, источник
  https://github.com/vehiclesdb/vehiclesdb, original Git blob
  \`c83f03e1c56384d8ff58fd8667635ecac88bc2c5\`.
- Сохранено **8 460 моделей / 499 марок** в допустимых категориях: легковые — 6 000;
  грузовики — 1 213; фургоны — 809; автобусы — 438.
  Мопеды и мотоциклы не импортируются. 55 невалидных для стабильных идентификаторов
  отдельных моделей пропущены и могут быть рассмотрены модератором.
- Полная исходная атрибуция сохранена в \`server/data/vehiclesdb_ATTRIBUTION.md\`,
  исходная лицензия — \`server/data/vehiclesdb_LICENSE.txt\`, ссылка на лицензию
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). UI и API показывают
  явную атрибуцию «Vehicle data by VehiclesDB», ссылку на все уведомления
  первоисточников и версию. Важно не удалять уведомления в следующих релизах.
- Грузовые Scania/Volvo/DAF/MAN/Renault/Iveco и легковые Toyota/Lada/BMW/…
  берутся из реального набора, не из вручную сочинённых списков. Это **названия
  марок и моделей** из реестров, не гарантия точной комплектации или VIN.
- Дата начала и окончания выпуска **не выдумана**: упрощённый исходный файл
  VehiclesDB не содержит подтверждённых дат по каждой модели. Выбор года в
  пользовательской форме есть, но его соответствие конкретному поколению
  нужно проверить дополнительно по независимым официальным источникам.
- **Прицепы:** исходный набор VehiclesDB не охватывает прицепы отдельной
  категорией; придумывать названия нельзя. Заявку на отсутствующий прицеп
  можно отправить модератору. Полное наполнение — отдельный пакет после
  NHTSA/vPIC или другой юридически допускаемой сверки.

### Схемы, оригиналы и разделение прав

- \`server/data/vehicle_technical_sources.json\` — 8 ПРЯМЫХ ССЫЛОК на
  изготовителей Scania, Volvo, ZF/WABCO, Knorr-Bremse. Это **индекс**
  официальных порталов, не украденные PDF. Заводской доступ может требовать
  логин, подписку или VIN. Для североамериканской Volvo не обещаем соответствие
  европейскому FH/FM.
- 6 оригинальных памяток TrackSOS для водителей: тормоза/EBS, зарядка,
  охлаждение, SCR/AdBlue, свет прицепа, шины. Водитель не получает
  схемы электрических подключений, кодировки ЭБУ, моменты затяжки и
  опасные пошаговые инструкции. Подробная техника — только специалисту.
- Профессиональную библиотеку может читать **действующий admin**
  либо подтверждённый мастер/эвакуаторщик/СТО. При наличии **обеих ролей
  на одном аккаунте** права действуют независимо от выбранного
  frontend-режима. Не используется персональный «вечный пропуск»
  по номеру телефона или обход блокировки/отзыва ролей.
- Модуль авторства материалов и общение водителей/мастеров уже
  развивается параллельно в PR #111 (разделы ТехБаза, Эфир, Клуб);
  **не создавать дубль** и не накатывать старые экраны на #111.
  Этот пакет добавляет своё дерево источников, а будущий
  интеграционный PR свяжет его с профессиональной ТехБазой.
- Открытый веб-экран \`#/vehicle-tech\` — только для авторизованных пользователей;
  профессиональная вкладка и её API закрыты для водителя/клиента.
  Справочная памятка не заменяет специалиста.

### Каталог и модерация

- \`/api/vehicle-reference/makes\` и \`/models\` работают с **реально**
  сохранённым срезом и серверными фильтрами по категориям/ролям,
  по поисковому тексту. Поиск не превращает найденную строку в
  самостоятельный пользовательский идентификатор; выбор марки и
  модели происходит по нормализованным ключам.
- В едином \`VehicleFields\` свободный ввод марки/модели заменён на
  поиск + 2 связанных списка. Прежде чем выбрать модель, нужно выбрать
  марку. В гараже POST через \`/api/vehicle-reference/vehicles\`
  валидирует ключи **на сервере** и сохраняет категорию, ключи,
  источник и версию. Старые записи сохраняются без принудительного
  исправления.
- «Нет машины в каталоге?» → \`vehicle_catalog_missing_requests\`.
  Кандидат не попадает в каталог автоматически, даже после
  модераторского «accepted». Принятие означает рассмотрение источников,
  затем отдельный лицензированный/проверенный релиз.
- Админская очередь /api/admin/vehicle-reference/missing с причинами
  и журналом. Пользователи видят только собственные запросы.
- **Важный оставшийся переход:** исторический API \`/api/vehicles\`
  ещё поддерживает старые приложения и тестовые сценарии;
  новые формы гаража используют исключительно строгий endpoint.
  Для полного прекращения прямого произвольного ввода через
  старый API требуется versioned migration и безопасная замена
  старых клиентов без поломки аварийного SOS. **Не считать
  аппаратное/серверное ограничение по всем старым версиям завершённым.**

### Доступные мастера действительно рядом

- \`/api/vehicle-reference/nearby\` возвращает возможность рекомендации
  только при координатах автомобиля и подтверждённом профиле
  исполнителя со статусом **online**, без активной работы/паузы/
  отпуска, с GPS **не старше 15 минут**, в радиусе минимум настройки
  dispatch и 70 км. Не выдаёт координаты/личные контакты исполнителя.
- В старом \`/api/masters-nearby\` запрещена выдача мастера как
  «подходящего рядом» без GPS клиента/исполнителя или при старом
  сигнале. Расстояние по прямой не является дорожным ETA.
- Это не гарантирует доступность исполнительного навигатора:
  требуется конечная проверка реальной локации, статуса,
  маршрута и отклика исполнителя перед выдачей обещания приезда.

### Проверки после большой выкладки

В одном CI после коммита:
1. TypeScript typecheck + server tests (в том числе новая миграция в
   одноразовой БД).
2. Каталог: реальный Renault Premium, Lada, 8460 моделей, недопустимый
   ключ, запрет легковых для клиента/допуск для мастера.
3. Гараж: валидный выбор, UUID/номер/версия, подделанная модель → 400.
4. Очередь: 1 заявка, повтор/подмена/модерация, роль клиента не может
   читать чужую очередь и профессиональные ссылки.
5. Права: admin+master, неподтверждённый мастер и водитель.
6. Мастера поблизости: пустые координаты, удалённость, занят,
   несвежий GPS, online, никакой придуманной ETA.
7. Web build/browser smoke, Android launch smoke, нагрузочный CI.
