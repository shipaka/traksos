# ABS без CAN — предложение к аппаратной архитектуре (26.11.2026)
Вопрос владельца и изготовителя: диагностика ABS при отсутствии CAN на ISO 7638. Предлагается добавить независимый защищённый K-line 24 В на отдельный герметичный сервисный разъём, с внешними пассивными кабелями для конкретных ЭБУ; сохранить ISO 7638 для питания по согласованной схеме и CAN ISO 11992. Это предложение, не утверждённая схема, распиновка или заказ компонентов. Не использовать контакт 5 ISO 7638 как K-line: это выход предупреждения ABS, для VCS II подтверждено разделом 2.1.5.1.
WABCO VCS II: Standard без интерфейса CAN тягач–прицеп; Premium и Separate ECU имеют ISO 11992; с 2005 года указана также диагностика через CAN для Premium и Separate ECU. K-line ISO 14230, KWP2000 или JED 677: Standard/Premium X6 контакт 8 (MOD RD 7); Separate ECU X1 контакт 2 (14/15 POWER/DIAGN). Это сведения из WABCO 8150100083, печатная стр. 10, разделы 2.1.7–2.1.8, визуально проверено; перед изготовлением кабеля проверить номер блока, ревизию, схему полного разъёма и вид контактов. https://www.wabco-customercentre.com/catalog/docs/8150100083.pdf
SORL ABS: официальный каталог подтверждает отдельный тестер 36302900020 и диагностические жгуты; K-line для прицепных ABS указан во вторичном руководстве, точные контакты/протокол конкретной модели не проверены. https://sorl.ru/manuals/rukovodstvo-dlya-diagnosticheskogo-oborudovaniya-sorl.pdf ; https://autogeriko.com/sorl---abs.html
Haldex U-ABS: отдельная диагностика и blink-code; уточнять физический интерфейс по варианту. https://www.haldex.com/sv/europe/trailer-application-guide/ebs/diagnostic/diag-tools/ ; https://www.haldex.com/globalassets/europe/tag/u-abs/u-abs-files/006300022_gb.pdf
Knorr KB4TA: J1939 на отдельных диагностических кабелях, blink-code; не считать J1939 электрически равным ISO 11992. https://manualzz.com/doc/42773168/knorr-bremse-kb4ta-d--trailer-abs-product-manual
Кандидат K-line transceiver TI TLIN2027-Q1 (24 V, 4–48 V supply, ISO 9141, open-drain RXD, 20 kbps TX, no dominant timeout); https://www.ti.com/product/TLIN2027-Q1 . Требуется проверка datasheet, нагрузки, уровней 3.3 В, внешней защиты, idle/bias, отказобезопасного аппаратного отключения TX при сбросе/зависании, импульсов и тайминга конкретного ЭБУ. Не подключать K-line к ESP32 напрямую. GPIO, защитные компоненты и разъём не выбраны. Blink-code — отдельный режим ручного ввода либо будущий защищённый вход, не подавать произвольные импульсы на вывод предупреждения.
Программно: отдельные профили транспорта и протокола, K-line initialization и чтение только по подтверждённым запросам, проверка ответа и тайм-аутов, неизвестный блок — остановка, без перебора команд; очистка только после подтверждения модели и отдельного испытания. Никаких параметрирований, управления клапанами, тормозами или обхода защит. Только неподвижный изолированный стенд. Текущая USB-прошивка не реализует эти интерфейсы. Никаких изменений утверждённой электрической схемы или UI этим документом.
