# Внутренний протокол, версия 1 — только симулятор
Не ISO 11992, не протокол модулятора. Транспорт BLE и ответы в байтах ещё не реализованы. Симулятор принимает 9 байт: version=1, opcode, sequence uint32 LE (1..2^32-1), payload uint8 (0..127), 2 нулевых зарезервированных байта. Opcode 1 state, 2 set light mask, 3 all off, 4 reset one fault, 5 heartbeat, 16–18 identify/read/clear (всегда UNSUPPORTED). Биты 0–6: левый поворот, правый поворот, туман, левый габарит, правый габарит, стоп, задний ход. Неподдерживаемые команды и повторы не продлевают сессию. Симулятор отключает выходы после 2 секунд без допустимого запроса; сброс защиты не включает канал. Все ошибки явно возвращаются. Реальный прибор потребует аутентифицированного BLE, nonce сессии, подтверждений состояния, независимого аппаратного watchdog, подтверждённой силовой схемы и стендовых испытаний. 
DTC: исходный код и статус не подменяются догадками. Расшифровка только по точному подтверждённому профилю и источнику. Каталог по умолчанию пуст, тестовые записи не входят в приложение.
