# Проверка собранного APK
PR CI теперь проверяет манифест самого unsigned release APK через SDK apkanalyzer, а не только исходный AndroidManifest. Проверяется package, min/target SDK, отсутствие debug/testOnly, backup и cleartext, наличие dataExtractionRules, строгий список разрешений и экспортируемых компонентов. Единственный разрешённый экспорт — launcher MainActivity; другие компоненты требуют явного exported=false. Новые разрешения и компоненты должны пройти отдельный review. SHA-256 APK и результаты записываются в JSON, файл выгружается отдельно от debug APK. При несовпадении проверка завершается ошибкой.
Локальная проверка подписанного APK: python tools/apk_security_review.py PATH_TO_APK --expected-signer-sha256 TRUSTED_CERT_SHA256 --output REVIEW.json. TRUSTED_CERT_SHA256 — заранее сверенный отпечаток сертификата выпуска из отдельного доверенного источника (не отпечаток, извлечённый из проверяемого APK). apksigner verify проверяет подпись, затем сравнивается единственный signer. Смена ключа или схемы ротации требует отдельного согласованного процесса. Проверка без параметра подписи не подтверждает подписанность/неподписанность APK; в PR она проверяет только манифест. Не публикует и не подписывает ничего. Требуются Android SDK apkanalyzer и apksigner при проверке подписи. Python tests проверяют правила на синтетическом XML, не заменяют реальную проверку артефакта в CI. 
Результат не удостоверяет поведение приложения, отсутствие уязвимостей, обфускацию всех данных, аппаратную безопасность или защищённый BLE. Текущий demo не является коммерческим релизом даже с подписью. Публичный репозиторий и доступные debug-артефакты не защищают исходники от копирования. Реальные ключи не хранятся в CI PR.
