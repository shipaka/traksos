# Утверждение владельца 26.11.2026
Владелец утвердил три визуальные концепции: освещение (фотореалистичный прицеп, выноски, тёмный графит, оранжевые действия), диагностика (сканирование, результаты, повтор/очистка), короткая заставка с фурой и Mini Диагностика. Нижняя навигация строго два раздела: Освещение слева, Диагностика справа. История внутри диагностики. Нет профиля, отдельной главной или обязательного аккаунта. После запуска — освещение. Оригинальный логотип с дорогой из 618.png, без перерисовки. Неподвижная иллюстрация; только световые секции и подсветка аварийки меняют яркость, без скачков. Правая сторона не видна в данном ракурсе, состояние по кнопке. Светофункции и аппаратные ограничения без изменений.
Реализация этого этапа: Compose, точный существующий логотип и дорожный иллюстративный ресурс, вырезка утверждённого изображения освещения (не фон всего UI), реальные нажимаемые кнопки, локальное затемнение областей фонарей, демонстрационное сканирование и отдельная локальная демо-история. Демо не взаимодействует с ECU; очистка заблокирована. Не выдавать демонстрационный прогресс/ошибки за реальную диагностику. Заставка не задерживает приложение искусственно; нативную загрузку и визуальное соответствие ещё проверять. Нужны реальный скриншот APK, проверка качества масок и правого борта, окончательная графическая приёмка после сборки.
