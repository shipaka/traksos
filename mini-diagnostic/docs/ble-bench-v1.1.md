# USB-only двусторонний стенд v1.1
Дополняет v1.0. Прошивка по-прежнему только для отдельной ESP32 от USB, без прицепа, силовой платы, CAN или 24 В. Никакого управления физическими выводами. Версия capability 54 53 4D 44 01 01 03 00. Новые характеристики: 7e625a12-5721-4cde-a84b-9e5fd1287410 (write with response), 7e625a13-5721-4cde-a84b-9e5fd1287410 (read). Пакеты 9/10 байт по внутреннему протоколу v1. Флаг simulated всегда 1. Плата хранит только маску виртуальных каналов в RAM. При тайм-ауте 2 с и разрыве связи маска сбрасывается; повторы и неподдерживаемые команды не продлевают тайм-аут. Не является аутентификацией, не использовать этот сервис для реальной нагрузки. Android выполняет фиксированный тест: STATE, SET_LIGHTS (виртуальная аварийка и стоп), повтор sequence, ALL_OFF, READ_DTC (обязательно UNSUPPORTED), STATE. Сверяет код ответа, sequence, флаг симуляции, маску и отсутствие виртуальных ошибок. Прерванная последовательность не считается пройденной. Реальная связь с физической платой пока требует испытания. CI: C++ host tests и Kotlin tests, затем отдельные APK и bench firmware. Согласованные экраны не изменены; диалог проверки Bluetooth уже существовал.
