# USB-only BLE bench v1
Этап предназначен только для отдельной ESP32 DevKit (ESP32-WROOM-32, обычный ESP32), питаемой по USB. Не подключать к прицепу, CAN-трансиверу или силовой плате: загрузочные состояния выводов ещё не проверены. Arduino Core 2.0.17 через PlatformIO espressif32 6.9.0 — выбран для минимального проверочного BLE-этапа, не финальная платформа серийной прошивки. Никаких операций GPIO/TWAI и никаких GATT write. Android: нажать на плашку виртуального адаптера, разрешить Bluetooth (на Android <=30 требуется геолокация для BLE-поиска, приложение её не собирает), «Найти ESP32». Поиск по UUID службы, первый найденный стендовый прибор используется для чтения фиксированной версии, затем соединение закрывается. Не является аутентификацией и не разрешает реальные выходы. Проверять одну ESP32 за раз; никаких адресов не сохраняется. Тайм-аут 15 с. При закрытии/сворачивании диалога поиск и GATT закрываются.
UUID service 7e625a10-5721-4cde-a84b-9e5fd1287410, read-only char 7e625a11-5721-4cde-a84b-9e5fd1287410. Точный 8-byte ответ 54 53 4D 44 01 00 01 00 (TSMD; версия 1.0; флаг bench-only; reserved). Неизвестные версии и флаги отклоняются.
Сборка: в firmware выполнить pio run -e esp32_bench_ble; прошивка только отдельной USB-платы командой pio run -e esp32_bench_ble -t upload после проверки выбранного порта и модели. CI отдельно собирает APK и firmware.bin; последний не полный образ флеша. Проверка на физической ESP32 ещё обязательна. Для реального управления — аутентификация и bonding, согласованная силовая часть, аппаратный fail-off, проверка режима после сброса, стендовые испытания. Не переносить тестовый BLE в рабочее управление напрямую.
Документация: https://developer.android.com/develop/connectivity/bluetooth/bt-permissions ; https://docs.platformio.org/en/stable/boards/espressif32/esp32dev.html
