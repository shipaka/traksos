# Проверка документированной диагностируемости
Не путать возможности заводского инструмента с реализованной совместимостью TrakSOS. На 26.11.2026 ни один реальный блок не испытан с нашим прибором.

| Система | Доказательство | Реализация TrakSOS | Пробел |
|---|---|---|---|
| WABCO VCS II Standard | 8150100083, §2.1.8: ISO 14230, KWP2000/JED 677; §5.3 и приложение 2: индикация текущей неисправности | 11 мигающих кодов для ручного поиска | Электрический K-line, инициализация, адреса, точные сообщения, испытание |
| WABCO VCS II Premium/Separate ECU | То же; CAN диагностика с 2005 года у указанных вариантов | Тот же ручной справочник | Ревизия, кабель, протокол и PHY |
| Haldex EB+ Gen1/2 | Официальный каталог: DIAG; ISO7638 CAN с ПО B337 (05/2005); более ранние системы требуют обновления через DIAG для этого пути | Сведения в реестре | Протокол сообщений, электрическая проверка, испытание |
| Haldex EB+ Gen3 | DIAG 814036001, ISO7638; руководство 2013, стр.105 | 17 текстовых кодов Info Centre 1 (выбранные записи) | Не переносить на числовые коды Info Centre 2 или DIAG+; нет транспортной реализации |
| Haldex EB+ 4.0 | H-CAN, кабель 844511065 | Сведения в реестре | Электрические параметры, точный протокол |
| Haldex U-ABS | Заводское ПО читает/очищает DTC | Сведения в реестре | Точная ревизия/интерфейс и протокол |
| WABCO TEBS D/E, VIE V1.01 | Существующие отдельные справочники | Ручной поиск | Реальная связь отсутствует |
| SORL, KORMEE, Экран | Ранее найденные сведения, требуется первичный источник по точной модели | Исследовательский реестр | Не объявлять рабочими |

Источники текущего этапа: WABCO https://www.wabco-customercentre.com/catalog/docs/8150100083.pdf (визуально сверены печатные стр. 10, 24, 28); Haldex https://www.haldex.com/en/europe/trailer-application-guide/ebs/diagnostic/diag-tools/ ; Haldex installation guide https://www.manualslib.com/manual/1181878/Haldex-EbPlus-Gen3.html?page=105 (сверен HTML-текст, 17 однозначно сопоставимых строк). Оригинал Haldex: https://www.haldex.com/globalassets/europe/61.-documents/ebs-system/006300018_en.pdf . Не копировать целые чужие руководства в публичный репозиторий без разрешения; хранить ссылки, редакции, страницы и собственные краткие справочные обозначения.
Мигающий код VCS II относится к текущей неисправности и не читает память. Вводится число вспышек вручную; отсутствие вспышек не трактуется как исправность. Не активировать режим через произвольные электрические импульсы. Haldex текстовые обозначения не дают уверенного диагноза детали или состояния памяти. Справочники не подключены к физическому транспорту.
