# Комплект прошивки для изготовителя
В CI добавлена сборка полного начального образа classic ESP32 4 MB (USB-only BLE bench). Образ содержит bootloader, partitions, boot_app0 и application. Пакет проверяет размеры, адреса, magic, раздел app, совпадение объединённых сегментов и SHA256. Windows launcher создаёт локальную Python venv, устанавливает закреплённый esptool 4.8.1, требует явного подтверждения модели/изоляции/порта, проверяет SHA256 и записывает полный образ. Инструкция и скрипт входят в архив. Не OTA, не готовая силовая прошивка. Сборка пакета и физическая прошивка подлежат проверке. Источник команд: https://docs.espressif.com/projects/esptool/en/release-v4/esp32/esptool/basic-commands.html .
