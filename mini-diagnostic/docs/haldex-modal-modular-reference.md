# Haldex MODAL / MODULAR — DDU/TODD
Источник: Haldex 700095-EN, печатные стр.18–19, PDF индексы 17–18: https://www.haldex.com/globalassets/europe/61.-documents/abs-system/700095-EN.pdf . Обе страницы визуально сверены. 52 отдельных справочных обозначения; общая заводская таблица для двух семейств, не удваивать число записей. Сокращённые собственные русские описания, не ремонтная инструкция. Сохраняется исходный формат кода, включая нули и буквы O в OA/OC/OE. Не переносить в U-ABS или MGX.
Исключены 00/07 (состояния), 37 (сигнал внешнего устройства), 88 (также тест сегментов при включении), CA/CC (сервисные приглашения), A1–A3 и db (индикация), E0–E9 (условие расхождения показаний DDU и TODD). В строке 92 документа противоречивый знак для 12 В; значение намеренно не перенесено. Считывание кодов DDU, память и наличие отдельного диагностического разъёма описаны на стр.13–17, но электрический интерфейс и протокол ещё не подтверждены для нашего прибора. Не воспроизводить команды очистки и не подменять отсутствие ошибок подтверждением исправности. MGX отдельно: https://www.haldex.com/globalassets/europe/61.-documents/abs-system/000700022_EN.pdf ; руководство 1999 года, семейства MGX, MGX2, MGX2E и MGX100. Оригинальный перечень цифровых кодов MGX не получен; не считать MODAL совместимым. 
Реестр: 15 из 34 позиций с частичным справочным покрытием. 786 записей редакций (прежние 734 + 52), не уникальные сырые DTC; 16 типов из памятки WABCO отдельно. Не утверждать реальную совместимость.
