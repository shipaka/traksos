# Встроенное справочное пособие — решение владельца
Внутри утверждённого раздела «Диагностика» добавлена кнопка «Справка: как подключиться». Пять справочных маршрутов: передний ISO 7638, боковой SOV/DIAG, непосредственно штатный диагностический порт модулятора, blink-code ABS, неизвестный блок. Работает офлайн. Никаких изменений нижней навигации. Справка не выбирает рабочий интерфейс, не подаёт питание, не запускает BLE или диагностику. При открытии прекращается виртуальный тест освещения/сканирования. Пока все физические подключения заблокированы на уровне отсутствующей реализации.
Памятка содержит общие объяснения, примеры, предупреждения и ссылки на документацию. Конкретные pinout/номера кабелей и фотографии с указателями — только после проверки точной модели, ревизии, ориентации контактов, электрических характеристик и прав на использование изображений. Не считать внешний вид розетки подтверждением совместимости. Источники для первых примеров: WABCO каталог диагностических кабелей 4463010230, https://www.wabco-customercentre.com/catalog/ru_RU/4463010230 ; Haldex SOV ISO11898 https://www.haldex.com/en/europe/trailer-application-guide/cables/u-abs-cable---sov-socket-to-diagn/ ; Haldex diagnostic tools https://www.haldex.com/sv/europe/trailer-application-guide/ebs/diagnostic/diag-tools/ .
Дальнейшая аппаратная реализация согласно approved-diagnostic-interfaces.md. Справочные маршруты не равны поддержанным профилям; проверка APK и физическое испытание остаются отдельными этапами.
