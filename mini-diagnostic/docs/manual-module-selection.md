# Автопоиск и ручной выбор
Обязательное требование владельца: общий поиск по установленному блоку и быстрый ручной выбор даже при неполной надписи на корпусе. Номер детали не обязателен для выбора семейства. Внутри диагностики добавлен выбор «Автопоиск / выбрать блок» и диалог с поиском по всем 34 позициям реестра. Пустой запрос показывает производителей; ввод маркировки ищет независимо от производителя. Пример TEBS E, TEBSE, ТЭПСЕ, TEPSYE → WABCO TEBS E как справочная подсказка. Общий TEBS оставляет несколько производителей/поколений. Алиасы — поисковые, а не доказательство модели; неизвестные обозначения не подставляются автоматически. Пользователь выбирает результат сам.
Ручной выбор хранится только в состоянии текущего экрана (не в постоянной памяти), при изменении отменяется текущий демо-тест и сбрасываются результаты. Можно вернуться к автоматическому поиску. Выбор не меняет фактический тип ЭБУ, не разрешает передачу запросов, не подаёт напряжение, не открывает очистку и не заполняет реестр сигнатур. Автопоиск остаётся демо до реализации и проверки транспорта. В дальнейшем, если электронная идентификация противоречит ручному выбору, остановить обмен и показать расхождение; для реально подтверждённого семейства использовать отдельный проверенный профиль кабеля, ревизии и протокола. Существующий экран освещения и два пункта нижней навигации сохранены. Добавление кнопки выбора внутри диагностики прямо запрошено владельцем.
