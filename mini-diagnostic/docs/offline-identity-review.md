# Офлайн-разбор идентификации
В существующей справке новый экран принимает отдельные ранее записанные полные ответы на идентификационные DID UDS. Ожидаемый DID явно указан в каждой строке, поддерживаются только перечисленные поля IdentityDid. Несовпадение DID, некорректные ответы, конфликт значений и превышение ограничений отклоняют весь набор. Отрицательный ответ не становится значением. Хранятся исходные строки, HEX и SHA-256 текста, который не удостоверяет происхождение.
ASCII — только возможное отображение строго печатных байтов без удаления нулей/пробелов, без BCD или угадывания формата. Только номер детали F187 может дать кандидатов по существующему точному каталогу; диапазоны, псевдонимы и синтетические данные исключены. Общий каталожный номер возвращает все семейства. Нельзя делать вывод о модели, версии, установленной ревизии или физическом источнике. Нет автоматического изменения выбора, разрешения транспорта, подписи профиля или связи с базой DTC. Реальные сигнатуры и заводские диагностические профили по-прежнему требуют подтверждённых стендовых записей. Тесты проверяют конфликт, адресуемое поле, отрицательные ответы и неоднозначность. Новых кодов неисправностей нет.
