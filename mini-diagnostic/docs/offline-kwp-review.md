# Android — проверка записанного кадра KWP
Третья вкладка внутри существующего офлайн-разбора, не новый пункт нижнего меню. Использует имеющийся KwpFrameDecoder. Принимает один полный кадр ISO 14230-2 поддерживаемого формата, до 260 байт; проверяет длину и контрольную сумму. Опционально сопоставляет явно введённые адреса ожидаемого физического ответа, но не обнаруживает адреса, не подтверждает направление записи или источник. Не разбирает сервисные DTC, не запускает K-line, не инициирует сессию, не передаёт команд. Неподдерживаемые заголовки и несовпадения отклоняются. Пример синтетический, адреса произвольные. Отчёт сохраняет исходный HEX в нормализованном виде. 
CI мини-диагностики: cancel-in-progress=false вместо постоянной отмены активного теста. GitHub сохраняет последнюю ожидающую проверку; выполняющаяся может закончиться. Добавлена выгрузка XML результатов unit-тестов даже при ошибке сборки. Основные workflow проекта не изменены. Новые коды неисправностей не добавлены.
