# Реестр завершённых поисков DTC — 26.11.2026

Цель: прекратить повторные проходы по одинаковым документам и зеркалам. Статус «закрыт публичный поиск» означает отсутствие новых доказательных данных в выполненных запросах, а не полное покрытие ECU или доказанное отсутствие документа во всём интернете. Приоритет 2018–2026; только электронная прицепная диагностика. Не использовать ламповые коды, таблицы тягачей и 12-вольтовых систем вместо 24-вольтовых.

## Правила продолжения
- Идентификатор документа + редакция + страница — ключ дедупликации. Зеркала, переводы и повторная выдача того же PDF не являются новыми источниками.
- Не повторять запросы по закрытым строкам без новой редакции, нового документа, конкретного отчёта или доступа к разрешённому источнику.
- Сохранять предварительный статус, если не удалось проверить страницу; никогда не синтезировать коды из последовательности или комбинации SPN/FMI.
- Открывать вопрос снова только при наличии указанного ниже нового материала. Никакого обхода авторизации или ограничений лицензии.
- Физическая совместимость и сырые DTC остаются отдельной задачей. Не выдавать справочные записи за проверенное подключение.
