TrakSOS Mini Diagnostic — USB-only BLE bench
ТОЛЬКО отдельная ESP32-WROOM-32 (классическая ESP32, 4 МБ flash).
Не подключать прицеп, силовую плату, CAN или 24 В. Прошивка не управляет выходами.
1. Установите Python 3 для Windows (python.org), если его нет. Нужен интернет для установки esptool.
2. Распакуйте весь архив в отдельную папку. Подключите ESP32 кабелем USB с данными.
3. Запустите FLASH-WINDOWS.cmd. Подтвердите модель и выберите COM-порт.
4. Если порт не виден, проверьте кабель и драйвер USB-UART CP210x/CH340 согласно модели платы.
5. При ошибке входа в загрузчик проверьте инструкцию платы (BOOT/EN); не выбирайте другую микросхему.
6. После успешной записи откройте APK, нажмите плашку адаптера, «Найти ESP32».
   Ожидается сообщение о прочитанной версии стендового протокола.
Файл bin — полный начальный образ по адресу 0x0; не OTA, не обновление поверх рабочей коробочки.
Скрипт сверяет контрольную сумму с manifest.json; это не цифровая подпись. Используйте архив только из официального CI проекта.
Никогда не прошивать этим образом другой ESP32 (S3/C3 и т.п.) или прибор с уже подключённой силовой электроникой.
